How one counter check moves through the code

From the transaction form to the audit log. Everything runs in one Python process on the branch PC's CPU, and the offline guard blocks any connection that isn't to the machine itself. kavach/pipeline.py runs the analysis for the app, the eval and the benchmark, so all three use the same path.

One check, end to end

Inside the LLM step

One generation per check, plus at most one retry. The first attempt skips grammar-constrained decoding because it cost about 0.08 s per output token on this CPU. The retry uses the JSON-schema grammar, which guarantees valid JSON.

How the level is decided

Fusion averages the scores it has, turns the average into a level, then applies two kinds of rule. Hard overrides force HIGH. Floors lift a LOW to MEDIUM, which catches coached victims who deny everything while on a call.
